# EL HORNERO - Materiales para la construccion - Proyecto individual para el curso Front-End Js, de TalentoTech 2026
El hornero es una página web desarrollada para una tienda de materiales de la construcción.
Su objetivo es presentar productos, mostrar reseñas de los clientes y facilitar el contacto con potenciales compradores.

## 🛠️ Tecnologías Utilizadas
- HTML5: estructura y diseño
- CSS: Flexbox, CSS Grid y estilos
- Google fonts: fuente personalizada
- Formspree: gestión del envío del formulario del contacto
- Fontawesome: Íconos
